## Commit Convention | Type | Description | | -------- | -------------------------------------------- | | feat | 새로운 기능 추가 | | fix | 버그 수정 | | docs | 문서 관련 | | style | 스타일 변경 (포매팅 수정, 들여쓰기 추가, ..) | | refactor | 코드 리팩토링 | | test | 테스트 관련 코드 | | build | 빌드 관련 파일 수정 | | ci | CI 설정 파일 수정 | | perf | 성능 개선 | | chore | 그 외 자잘한 수정 | EX) feat : header 개발 위와 같은 Commit Convention으로 지금까지 했던 내용들을 한국어로 기능별로 나눠서 커밋해줘.
